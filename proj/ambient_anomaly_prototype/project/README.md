# Ambient Smart-Home Anomaly Detection — Prototype

A small, privacy-preserving research prototype that detects routine deviations
(prolonged inactivity, unusual nighttime movement, missed daily routines) from
ambient smart-home sensor data.

**This is a research prototype, not a medical-grade or production system.**

---

## Quick start

```bash
# 1. install dependencies (Python 3.10+)
pip install pandas scikit-learn matplotlib streamlit

# 2. generate the simulated dataset (writes data/sensor_events.csv)
python scripts/simulate_data.py

# 3. run the evaluation (prints scenario results, latency, false-positive rate)
python scripts/evaluate.py

# 4. (optional) regenerate the report figures
python scripts/make_figures.py

# 5. launch the dashboard
streamlit run app.py
```

## What it detects

| Scenario                          | Detector              | Threshold                          |
|-----------------------------------|-----------------------|------------------------------------|
| Prolonged daytime inactivity      | rule (statistical)    | ≥ 6 h with no events, 08:00–20:00  |
| Unusual nighttime activity        | rule (baseline ratio) | 01:00–04:00 events ≥ 2× baseline   |
| Missed morning kitchen routine    | rule (presence)       | 0 kitchen events 07:00–09:00       |
| General "novel" hours             | IsolationForest       | per-hour-of-day, contamination=5%  |

Alerts are de-duplicated with a 4-hour cooldown per alert type.

## Data & privacy

- Sensor IDs are anonymized room/device tags (e.g. `MOTION_KITCHEN`,
  `PRESSURE_BED`). No personal identifiers are collected.
- No audio or video is captured.
- All processing runs locally; data does not leave the host.
- Aggregation to 1-hour windows limits behavioural reconstruction.

A full privacy statement is in `REPORT.md`.

## Switching to real CASAS data

The preprocessing module expects a CSV with columns
`timestamp, sensor_id, event`. Most CASAS datasets can be reduced to this
schema with a short adapter; nothing else in the pipeline needs to change.
